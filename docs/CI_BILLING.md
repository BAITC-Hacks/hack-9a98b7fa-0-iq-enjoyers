# Красные проверки GitHub Actions: блокировка биллинга

23 сентября 2026 пользователь прислал аннотацию:

> The job was not started because your account is locked due to a billing issue.

Задание Python 3.11 не стартовало. Python 3.13 затем отменён матрицей из-за
первого сбоя. Эти статусы не являются результатом исполнения наших тестов.
Предупреждение о будущей миграции ubuntu-latest — отдельное уведомление.

## Что нужно сделать владельцу

Репозиторий находится в организации BAITC-Hacks. Администратору организации
нужно проверить биллинг и доступность Actions у владельца репозитория,
устранить причину блокировки или обратиться в GitHub Support. Секреты,
карты и пароли не нужно передавать разработчику или сохранять в Git.

После разблокировки открыть Actions → нужный запуск → Re-run failed jobs.
Правка Python, API-ключ модели или увеличение timeout эту блокировку не снимают.

Сообщение организаторам:

«Проверки репозитория не запускаются: GitHub пишет account is locked due to
a billing issue. Пожалуйста, проверьте биллинг владельца BAITC-Hacks и разблокируйте
Actions. Локальные проверки Python 3.11/3.13 выполнены; результаты приложены».

## Что уже улучшено в workflow

Зафиксирована Ubuntu 24.04, добавлены названия шагов, проверка зависимостей,
тайм-аут задания и сохранение JUnit. fail-fast выключен, чтобы после снятия
блокировки одна версия Python не отменяла другую. Проверки не отключены;
зелёный удалённый статус не заявляется без фактического запуска GitHub.

## Локальная проверка до дедлайна

В подготовленном окружении:

```bash
python -m pip check
python -m pytest tests -q
python scripts/check_publish.py --worktree
python run.py --offline --runs 10
```

Последняя команда требует официальный ZIP и подготовленное .venv-agent;
формирует submission.csv и проверяет его независимым валидатором.
Локальный отчёт не подменяет GitHub check, но позволяет сдать воспроизводимый код.

Официальные источники:
[биллинг Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions),
[поддержка GitHub](https://support.github.com/).
