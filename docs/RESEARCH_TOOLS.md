# Архив инструментов исследования

Эти утилиты предшествовали/сопровождали выбор кейса. Они не являются конкурсным
Agent и не нужны для сдачи ProfitPilot. Актуальный запуск: [README](../README.md).

## Общий поиск telecom-идей

Из корня репозитория, без зависимостей и ключей:

```bash
python3 telecom_idea_research.py --offline
```

Результаты: `research_output/top_10_ideas.md` и `.json`. Ранние идеи про NOC,
покрытие и энергосбережение не заменяют текущую задачу тарифных кампаний Beeline.

## Необязательная внешняя рецензия

`beeline_research/review_with_glm.py` готовит запрос с запиской и источниками.
Просмотреть его без обращения к модели:

```bash
python3 beeline_research/review_with_glm.py --dry-run
```

Зависимости сетевых исследовательских утилит отдельные от конкурсного агента:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-research.txt
```

После локальной настройки `NVIDIA_API_KEY` можно запустить рецензию; для поиска
GitHub необязателен `GITHUB_TOKEN`. Значения ключей не публикуйте. Они не нужны
конкурсному оценщику. Brev и inference API используют разные типы ключей.

Исторически выбран идентификатор `z-ai/glm-5.3`; пример не подтверждает его
доступность или успешный вызов. Рецензент не открывает ссылки сам, а ответ LLM
не является независимым подтверждением фактов. В конкурсном агенте предусмотрен
другой необязательный путь — [локальная Ollama](LOCAL_LLM.md).
