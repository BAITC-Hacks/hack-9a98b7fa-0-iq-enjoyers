# Проверка запуска и надёжности — 23 сентября 2026

**Архив режима fixed.** Сохранены первоначальные результаты и хеши.
[Актуальный режим transfer и проверки](transfer_release.md).

Цель — запуск без правки исходников, воспроизводимые зависимости, отсутствие
тихого успеха при некорректном результате. Это не обещание 25 баллов:
оценку ставят организаторы на своей среде и данных.

## Что исправлено

- Первый временный сбой пилота больше не завершает исследование сразу.
  Повтор допустим только без списания ресурсов; максимум три попытки одного
  действия, максимум 20 запросов. При списании ресурсов повтор вслепую запрещён.
- Не менее одного пригодного пилота обязательно. Постоянный отказ или NaN
  приводят к явной ошибке вместо непроверенной стратегии.
- Ячейки >5000 делятся только публичными фильтрами data/call. Если допустимое
  разбиение невозможно, агент явно сообщает об этом, а не возвращает пустой план.
- Запуск `python3 run.py` подготавливает отдельное окружение, тестирует, оценивает
  и формирует пакет. Можно указать ZIP параметром; локальные пути не зашиты.
- Перед успехом независимый валидатор проверяет публичные аудитории, расходы
  пилотов/финальных кампаний, контакты, число кампаний, время и совпадение CSV.
- Ключи не передаются дочернему оценщику. Исходные данные и среда не публикуются.

нулевой бюджет, отказ оптимизатора, запуск offline и отрицательные тесты валидатора.

Результаты всех 100 seeds совпали с версией до исправлений: изменения
обрабатывают граничные ситуации и не подгоняют стратегию под неудачный seed 67.
Отрицательный результат −39 остаётся: техническая корректность не гарантирует прибыль.

Первый `python3 run.py --runs 10` сам установил зависимости в новое
`.venv-agent`, выполнил 41 тест, 10 оценок и сборку CSV. Повторный запуск
из `/tmp` абсолютным путём с `--offline --runs 1` также прошёл: PASS,
net 834 996, пять финальных кампаний. Основной агент не требует внешнего API.

Проверка чистой копии: коммит `79899ab` клонирован локально в новый временный
каталог без `.env`, артефактов и прежнего окружения. Одна команда
`python3 run.py --bundle <ZIP> --runs 1` установила зависимости, прошла 41 тест,
получила официальный PASS/net 834 996 и собрала проверенный пакет. Исходники
не менялись. Это локальный чистый clone, не результат удалённого GitHub Actions.

Дополнительный контрактный опыт: только в локальной тестовой копии уменьшен
порог разбиения до 500, чтобы активировать фильтры на реальном публичном CSV.
Неизменённая официальная среда приняла их: 18 пилотов с дополнительными
фильтрами, итог PASS и независимая проверка пройдена. Это тест совместимости,
не альтернативная стратегия и не часть таблицы результатов выше.

## Входные файлы и воспроизведение

Повторно сверены последние файлы Beeline в Downloads: оба хеша совпадают
с сохранённым [аудитом](../beeline_research/downloads_review_ru.md).
Файл с расширением `.docx` по содержимому является PDF. Внутренние исходники
среды/скоринга не исследовались; официальный пакет запускался без изменений.

Локальные подтверждения не включены в Git (содержат копии пакета организатора):

- `artifacts/20260923-161555-68c30abb/manifest.json` — 100 прогонов и валидация.
- `artifacts/ready-20260923-161722-a36df51c/summary.json` — первый запуск одной командой.

Установка зависимостей не входит во время `Agent.act`. `--offline` означает
отсутствие установки пакетов, а не изоляцию сети на уровне ОС. Новая версия
официального ZIP, иные условия судей или полностью недоступная среда требуют
отдельной проверки. GitHub Actions настроен на 3.11/3.13; его удалённый статус
нужно смотреть отдельно от выполненных локальных тестов.
